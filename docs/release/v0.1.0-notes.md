# v0.1.0 — Initial OSS Inference Gateway Source Preview

**SOURCE-ONLY PRE-RELEASE.** An early MIT-licensed preview for development,
experimentation and self-hosting. No prebuilt Docker image is published.

## Security Notice — Review Before Self-Hosting

Tested Docker images have unresolved Debian OS findings: **0 CRITICAL / 44 HIGH /
58 MEDIUM / 61 LOW / 1 UNKNOWN**. Image-security approval remains **FAIL**. The
owner accepts source publication separately; this is not unrestricted

Operators must review security, provider data policies, credentials, dependencies,
network exposure and their container environment. **GW-20 remains BLOCKED**: real
Cloudflare Workers AI/Ollama inference has not been live-verified. Offline loopback
HTTP tests do not prove genuine model execution. Source jobs pass while image

Read [security findings](security-findings.md), [verification](verification.md),

## Included

- Headless FastAPI inference gateway replacing the old prototype.
- Explicit Cloudflare Workers AI and Ollama provider registration.
- Provider routing and bounded, consented fallback with policy limits.
- JSON/SSE responses, genuine provider/model fields and truthful errors.
- Separate inference/admin authentication, private initialization and bounded requests.
- Optional authenticated Streamlit UI and CLI; enrichment disabled by default.
- **117 offline tests passing on Python 3.12 and 3.13**, including real loopback
  HTTP transports, stable OpenAPI and actual Gitleaks merge-history regressions.
- **23 PASS / 0 FAIL / 1 BLOCKED** SPEC-001 acceptance. GW-21 records complete CI
  execution/provenance; it does not approve the failed image-security gate.

The API is not OpenAI-compatible. No additional provider, managed deployment,
automatic model download, durable multi-instance quota or billing guarantee is
implemented. Provider service terms and model licenses are operator responsibilities.
